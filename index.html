Interactive states

Every state-capable family (text, bg, border, shadow, text-bg, text-bg-outline, fill, stroke) supports the same hover:, focus:, focus-visible:, active:, disabled:, group-hover: and theme + state (dark:hover:) prefixes shown here on text and background colors.

Hover this text hover:text-blue-500

Hover in dark theme dark:hover:text-red-500

Hover this card group-hover:text-blue-500

Hover the card, not this text group-hover:bg-purple-500
